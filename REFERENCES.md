# Development Notes

## Installation
### Frontend
```bash
# Init React-Vite project with TypeScript + React Compiler
npm create vite@latest .

# Install dependencies
npm install @reduxjs/toolkit react-redux
npm install @mui/material@^7.0.0 @mui/icons-material@^7.0.0 @emotion/react @emotion/styled 

# Run
npm run dev
```

### Backend
```bash
# Init project
npm init

# Install dependencies
npm install express mongoose cors nodemon

# Run
npm start
```
